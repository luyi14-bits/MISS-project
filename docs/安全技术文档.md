## 1. 安全架构总览

```
┌─────────────────────────────────────────────────────────────────┐
│                     MISS 桌面版安全架构                            │
├──────────┬──────────┬──────────┬──────────┬──────────────────────┤
│ 传输层    │ 认证层    │ 应用层    │ 数据层    │ 运维层               │
├──────────┼──────────┼──────────┼──────────┼──────────────────────┤
│ 进程内调用 │ AuthToken│ instructor│ Fernet   │ build.ps1 4 阶段验证 │
│ (零网络)   │ 中间件    │ 强制Schema│ AES-128  │ .pdb/.db/.env 清理   │
│          │          │          │          │                      │
│ 仅127.0.1│ level 2  │ 三级API   │ LiteDB   │ .gitignore 10 条加固 │
│ 绑定      │ bypass   │ fallback  │ PythonEnc│ obj/bin/dist/pub 排除│
│          │          │          │          │                      │
│ CORS白名单│ PUBLIC_  │ StreamSSE │ Runtime   │ Stage 4 去匿名化检查 │
│ 严格控制   │ PATHS    │ 安全占位符 │ Override  │ 37 项自动验证通过    │
└──────────┴──────────┴──────────┴──────────┴──────────────────────┘
```

**核心原则**：
- **纵深防御**：5 层各自独立防护，单层失效不导致全局攻破
- **默认拒绝**：所有端点默认不可访问，仅白名单放行
- **最小权限**：本地 single-user 模式，不对外暴露任何网络接口
- **静默降级**：安全组件失败时拒绝服务而非绕过（安全占位符 > 原文透传）

## 2. 威胁模型

### 2.1 攻击面矩阵

| 攻击向量 | 威胁等级 | 当前防御 | 残余风险 |
|----------|----------|----------|----------|
| 本地恶意进程调 API | 🟠 中 | AuthMiddleware Bearer Token | 仅当 token 泄露或未设置时风险 |
| 文件系统读取 .db/.env | 🟡 低 | Fernet 加密 + .env 不落盘 | 内存 dump 可提取 Fernet key |
| DLL 劫持 (python312.dll) | 🟢 低 | 嵌入 python/ 优先搜索，系统 fallback 才有风险 | 需要 Administrator 权限 |
| Prompt 注入 | 🟡 中 | instructor schema 约束 + system prompt | LLM 天生不可完全约束 |
| 流式输出 XSS | 🟢 低 | escapeHtml() + 安全占位符（非原文透传） | 前端 DOM 操作本身正确 |
| API Key 泄露 | 🟢 低 | sessionStorage + 内存 Only + 不落盘 + 不回传 | 进程 dump 可提取 |
| 构建产物路径泄露 | 🟢 零 | build.ps1 全自动清理 + .gitignore 全覆盖 | 无 |

### 2.2 STRIDE 分析

| 威胁类别 | 实际风险 | 缓解措施 |
|----------|----------|----------|
| Spoofing（伪装） | 本地进程冒充客户端 | AuthMiddleware 校验 Bearer Token |
| Tampering（篡改） | 数据库文件直接修改 | Fernet 加密使篡改不可读 |
| Repudiation（抵赖） | N/A（单用户桌面应用） | — |
| Information Disclosure | 日志/异常泄露 Key/路径 | 安全占位符 + 日志不记 Key |
| Denial of Service | Token 资源耗尽 | slowapi 限流 10/min per endpoint |
| Elevation of Privilege | N/A（单用户 localhost） | — |

## 3. 纵深防御体系

### 3.1 层级一览

```
┌──────────────────── 第 1 层：传输安全 ────────────────────┐

│ CORS ALLOWED_ORIGINS 白名单 4 项                           │
└───────────────────────────────────────────────────────────┘
                           │
┌──────────────────── 第 2 层：认证鉴权 ────────────────────┐
│ AuthMiddleware — Bearer Token 校验                        │
│ PUBLIC_PATHS 白名单：/health /api/info /docs               │
│ access_token 为空时自动 bypass（单用户模式）                │
│ 两处 sk-placeholder + your_openai_api_key_here 双检查       │
└───────────────────────────────────────────────────────────┘
                           │
┌──────────────────── 第 3 层：应用安全 ────────────────────┐
│ Pydantic Field 强制校验（max_length 4000，ge=-100 le=100）│
│ slowapi 频率限制：10/min chat，5/min character             │
│ instructor + pydantic 约束 LLM 输出 schema                │
│ 三级 API fallback：TOOLS → JSON → Raw（全网API兼容）      │
│ Stream SSE：_parse_json_response 失败 → 安全占位符         │
│ ⚠ 禁止原文透传（防 system prompt 泄漏）                    │
└───────────────────────────────────────────────────────────┘
                           │
┌──────────────────── 第 4 层：数据安全 ────────────────────┐
│ crypto.py — Fernet AES-128-CBC 加密对话内容                │
│ LiteDB SaveMessages → PythonBridge.EncryptMessage → Fernet │
│ API Key 仅 Python _runtime_overrides 内存持有（不落盘）     │
│ SaveSettings 序列化前清除 openai_api_key="""               │
│ load_dotenv + pydantic-settings 双重管理                   │
└───────────────────────────────────────────────────────────┘
                           │
┌──────────────────── 第 5 层：运维安全 ────────────────────┐
│ build.ps1 — 4 阶段全自动零泄漏打包                          │
│ 打包前清空 publish/ 防旧残留                                │
│ .env* .db .pdb .instance .pyc .sqlite3 全覆盖清理           │
│ Stage 4 自动验证 8+3+3 项关键产物                           │
│ .gitignore 37 条规则覆盖 obj/bin/dist/build/publish         │
└───────────────────────────────────────────────────────────┘
```

### 3.2 安全决策树

```
用户请求
  │
  ├── 路径在白名单？ → 放行（/health /api/info）
  │
  ├── 有 Bearer Token？
  │   ├── YES → 校验 → 放行/拒绝
  │   └── NO  → access_token 为空？ → 放行（单用户模式）
  │                                  → 不为空 → 401
  │
  ├── 请求体校验 → Pydantic Field → 422（超长/非法类型）
  │
  ├── 频率检查 → slowapi limiter → 429（超频）
  │
  ├── LLM 调用 → instructor TOOLS → 成功 → 返回
  │            → 失败 → JSON mode → 成功 → 返回
  │                    → 失败 → Raw API → 成功 → 返回
  │                            → 失败 → 安全占位符
  │
  ├── 响应过滤 → KnowledgeFilter → 教育水平/域名约束
  │
  └── 持久化 → encrypt(spoken) → SQLite + LiteDB 双写
```

## 4. 安全模块详解

### 4.1 加密模块 — `services/crypto.py`

| 属性 | 值 |
|------|-----|
| 文件 | [miss-backend/services/crypto.py](file:///d:/Desktop/MISS/miss-backend/services/crypto.py) |
| 算法 | Fernet (AES-128-CBC + HMAC-SHA256) |
| 密钥来源 | `MISS_FERNET_KEY` 环境变量 → 每次启动生成新密钥（告警） |
| 向后兼容 | 明文数据（无 `ENC_V1_` 前缀）直接返回 |
| 精确异常 | `except (binascii.Error, ValueError)` — 不吞 MemoryError |

```python
encrypt("hello") → "ENC_V1_gAAAAAB..."  # base64(Fernet.encrypt)
decrypt("ENC_V1_gAAAAAB...") → "hello"
decrypt("明文数据") → "明文数据"           # 向后兼容
```

### 4.2 认证模块 — `middleware/auth.py`

| 属性 | 值 |
|------|-----|
| 文件 | [miss-backend/middleware/auth.py](file:///d:/Desktop/MISS/miss-backend/middleware/auth.py) |
| 协议 | HTTP Bearer Token |
| 白名单 | `/health` `/api/info` `/docs` `/redoc` `/openapi.json` |
| 单用户模式 | `access_token == ""` or `"change-me-in-production"` → 跳过校验 |

### 4.3 LLM API 安全 — `services/llm_caller.py`

| 属性 | 值 |
|------|-----|
| 文件 | [miss-backend/services/llm_caller.py](file:///d:/Desktop/MISS/miss-backend/services/llm_caller.py) |
| 一级回退 | `instructor.Mode.TOOLS`（OpenAI 官方 API）→ 失败 → Level 2 |
| 二级回退 | `AsyncOpenAI + response_format={"type":"json_object"}` → 失败 → Level 3 |
| 三级回退 | 裸 API（SillyTavern 风格，纯 prompt 约束）→ 失败 → 安全占位符 |
| 安全占位符 | `"响应格式异常，请重试"`（非 LLM 原文，防 system prompt 泄漏） |
| 流式解析失败 | `_parse_json_response` → 安全占位符 + discard raw text |
| API Key 检查 | `sk-placeholder` + `your_openai_api_key_here` 双检查 |

### 4.4 打包安全 — `build.ps1`

| 阶段 | 操作 | 安全效果 |
|------|------|----------|
| Stage 0 | 验证 Python zip + miss-backend 存在 | 防止空构建 |
| Stage 1 | `dotnet publish` /p:DebugType=none /p:DebugSymbols=false + 清空旧 publish/ | 无 .pdb 残留 |
| Stage 2 | `python312._pth` 移除 `.` | 防 CWD 导入劫持 |
| Stage 3 | `.env*` `.db` `.pyc` `.instance` `.gitignore` 全覆盖清理 | 零密钥/数据库泄漏 |
| Stage 4 | 验证 8 项产物 + `.env` 泄漏 + `.pdb` 泄漏 + `.db` 泄漏 + `.instance` 泄漏 | 发布前自动阻断 |

## 6. 安全检查清单

### 6.1 上线前检查（每次发布）

- [ ] `build.ps1` Stage 4 全绿（8 项产物 + 3 项去匿名化）
- [ ] `.pdb` `.env` `.db` `.instance` 零残留
- [ ] `miss-backend/.env` 不存在
- [ ] `dotnet build` 0 error
- [ ] `pytest` 190/190
- [ ] `git status` clean（无未提交的 .env / .db）
- [ ] `git ls-files | grep "\.pdb\|\.exe\|\.db\|\.sqlite3"` 返回空

### 6.2 代码审核检查（每次 PR）

- [ ] 新增端点有 `Field(max_length=)`？
- [ ] 新增 except 有 `logging.warning/error`？
- [ ] 新增 LLM 调用走 `LLMCaller.call()` 而非直接 SDK？
- [ ] 新增 JSON 解析有 `json.JSONDecodeError` catch？
- [ ] 返回用户的内容经过了 `escapeHtml()` 或等效转义？
- [ ] 日志中不含 API Key / Token / 用户消息内容？
- [ ] 不返回 `_diag` / `traceback` / 内部路径？
- [ ] 非白名单路径有 Bearer Token 校验？

### 6.3 密钥安全清单

- [ ] `.env` 在 `.gitignore` 中
- [ ] API Key 仅内存持有（`_runtime_overrides`），不落盘
- [ ] 序列化前清除 `openai_api_key`
- [ ] `settings GET` 仅返回 `openai_api_key_set: bool`
- [ ] 无 `print(api_key)` / `console.log(api_key)`
- [ ] `MISS_FERNET_KEY` 环境变量已设置（生产）
