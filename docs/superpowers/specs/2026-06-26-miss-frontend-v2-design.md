## 一、项目背景

MISS（AI Companion）是一个基于双轨思维与动态属性系统的 AI 虚拟伴侣项目。后端已完成 Phase 0-3 核心管线（FastAPI + SQLAlchemy + Jinja2），现需对前端 UI 进行重构，从简易聊天页升级为桌面端全功能 SPA。

目标：**高度可视化、简洁轻量、桌面端优先、类似 Windows 图形化操作体验**。

---

## 二、技术约束与平台

| 约束 | 说明 |
|------|------|
| **平台形式** | 纯浏览器端 SPA（单一 `index.html` + 内联 CSS/JS） |
| **部署方式** | 放在 `miss-backend/frontend/` 目录，FastAPI 静态文件服务 |
| **通信方式** | `fetch()` → 后端 `POST /api/chat` + `POST /api/chat/stream` + `/api/preset/*` |
| **会话隔离** | `localStorage` 存储 `session_id`（`crypto.randomUUID()`） |
| **无外部依赖** | 不使用 React/Vue 等框架，纯原生 HTML/CSS/JS |
| **桌面端优先** | 最小可用宽度 900px，推荐 1280px+ |

### 5.3 属性面板

| 子组件 | 交互 | 说明 |
|--------|------|------|
| ⑨模式徽章 | education_level=-100 时显示 | 冰蓝渐变底 `#00BFFF`，文字"❄ ⑨模式 已激活" |
| 属性标签 | 静态 | 每个属性一行：标签名 + 脏标记圆点 |
| 滑块 `<range>` | 拖动即时改变本地值，不发送请求 | 宽 4px，圆角滑块 14px |
| 数值输入 `<number>` | 直接键入数值，Enter 确认；边界自动修正 | 宽 38px，与滑块双向联动 |
| 脏标记 | 属性值与已应用值不同时出现 | 5px 暖黄色圆点 `#D4A857` |
| 亲密度滑块 | 唯一红色渐变的滑块 | `#F5E0DC → #E8A090`，范围 0-100 |
| 文化水平滑块 | education_level=-100 时变冰蓝渐变 | `#87CEEB → #00BFFF`，触发⑨模式徽章 |
| [重置] 按钮 | 所有属性归零，清除脏标记 + ⑨模式 | 暖灰底 |
| [应用] 按钮 | 将当前值保存为已应用状态，清除脏标记 | 珊瑚粉底白字 |

### 5.4 右键菜单（预设用）

- 触发：预设列表项上 `contextmenu` 事件
- 菜单项：[应用] [导出 JSON] [删除（红色 #c0392b）]
- 关闭：点击菜单外部任意处
- 样式：白底 + `box-shadow: 0 4px 16px rgba(0,0,0,0.12)`

### 5.5 Toast 通知

- 位置：页面底部居中
- 样式：深棕底 `#4A3728` 白字，圆角 20px
- 动画：fade in 0.3s → 停留 1.8s → fade out
- 触发场景：属性应用/重置、预设操作、图片上传等

### 5.6 图片预览弹窗（正式版启用）

- 触发：点击聊天区图片消息
- 样式：全屏半透明黑底 `rgba(0,0,0,0.7)` + 居中图片
- 关闭：点击遮罩任意处

## 七、数据流

```
┌─────────────┐    POST /api/chat     ┌──────────────┐
│  前端 UI     │ ──────────────────→  │  FastAPI      │
│             │ ←──────────────────  │  后端         │
│  profile {} │   JSON response      │              │
│  session_id │                      │  PromptBuilder│
│             │                      │  → LLMCaller  │
└──────┬──────┘                      └──────────────┘
       │
       │ localStorage
       ├── miss_session_id: uuid
       └── (未来) miss_profile_cache
```

### 发送消息流程

1. 用户输入 → 按 Enter 或点发送
2. 构建 `POST /api/chat` body：`{ session_id, message, profile }`
3. 流式模式：SSE 逐 token 渲染 MISS 气泡 → done 时渲染 inner_thought
4. 非流式模式：一次性渲染 spoken + inner_thought
5. 用户消息和 MISS 回复均写入消息列表

### 属性调节流程

1. 拖动滑块 / 输入数值 → 仅本地更新 → ❌ 不发送
2. 点 [应用] → 更新 `appliedProfile` → ✅ 后续消息携带新 profile
3. 点 [重置] → 全部归零 → 自动应用

### 预设操作流程

1. 左键单击预设 → 立即填充属性值 + 自动应用 + Toast 提示
2. [⭐ 保存] → `POST /api/preset/save` → 刷新预设列表
3. [📂 导入] → 弹出文件选择器 → `POST /api/preset/import`
4. 右键 [导出] → `GET /api/preset/{id}/export` → 下载 JSON
5. 右键 [删除] → `DELETE /api/preset/{id}`

当 `education_level` 滑至 **-100** 时触发：

| 变化项 | 触发方式 |

## 九、待 Design 团队优化的方向

以下内容由 Design 团队自由发挥，以下仅为方向建议：

1. **头像设计**：当前用 emoji 占位（👤/🌸）。Design 可设计专属用户头像和 MISS 角色头像（含⑨模式的冰晶翅膀版本 `avatar_decor: "ice_crystal_wings"`）
2. **气泡样式细化**：可增加气泡小尾巴（三角形）、打字动画、MISS 回复的"正在输入..."状态
3. **滑块视觉升级**：可考虑渐变轨道（情绪化端偏红、理智端偏蓝）、自定义滑块图标
4. **空状态设计**：无会话时的引导页、首次使用的 Onboarding
5. **⑨模式全页主题联动**：education_level=-100 时全局色调变化（如加入冰蓝元素）
6. **预设卡片预览**：悬停预设时弹出迷你属性雷达图
7. **配色微调**：当前暖色系可在饱和度/明度上进一步精细化
8. **移动端适配**（可选）：当前为桌面端设计，未来如需响应式建议 768px 以下切换为单栏 Tab 布局
